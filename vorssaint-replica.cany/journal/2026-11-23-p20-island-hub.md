# P20 — 灵动岛 Sapphire 对齐（音乐/时钟 hero + 玻璃芯片行）
日期：2026-11-23 · 提交 7a8d818c · 1071 测试全绿 · pid 73451

## 为什么
用户："现在的灵动岛丑得简直没法看, Sapphire 没这么难看吧,整个 Lantern 的 UI 风格都要向 Sapphire 对齐.以及上岛的内容"——旧展开态=一排 8-11pt 等宽小字槽位挤在刘海下一行，确实丑。

## 新形态（Sapphire notch-hub DNA）
- **hero 区**：播放中→音乐卡（标题 13pt semibold/歌手 10pt/圆形播放键 34pt+前后曲）；无播放→大时钟（26pt rounded + 日期 11pt）
- **芯片行**：其余槽位=Sapphire widget 卡原语（白 0.08 底+10pt continuous 圆角+图标 10pt+等宽 11pt 值），横向 ScrollView 永不裁切
- **玻璃卡**：展开=ultraThinMaterial+黑 0.45 罩+白 0.12 描边+20pt continuous 圆角+阴影；待机=纯黑刘海幻觉不动
- **尺寸固定 340×(notch+88)**：hero+芯片行布局，槽位组合再多也不挤压（替代 130+46×n 公式）
- 内容预设：islandShowMusic=true、islandShowWeather=true（defaults write；memory/network 键删除回默认开）

## 测试
- ▶22 只钉 slotEnabled 语义与组归属，尺寸公式无断言——expandedSize 改固定值零测试影响；1071 全绿
